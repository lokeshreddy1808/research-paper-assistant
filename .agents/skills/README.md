# 3D Website Development Skills Suite

This custom skills suite was installed from `agentic-awesome-skills` to equip Antigravity with complete end-to-end expertise for building cutting-edge, award-winning 3D web applications, WebGL visualizers, interactive scenes, and spatial user interfaces.

Skills are installed **globally** in `~/.gemini/config/skills/` (for all projects) and **locally** in `.agents/skills/` (for this project).

---

## 🚀 Installed Skills Directory

### 1. Core Three.js & WebGL Architecture
- **`threejs-skills`**: Master procedure for setting up high-performance 3D scenes, rendering loops, and WebGL architectures.
- **`threejs-fundamentals`**: Scene graph hierarchies, camera configuration (Perspective & Orthographic), WebGLRenderer settings, and coordinate systems.
- **`threejs-geometry`**: Built-in geometries, BufferGeometry, custom vertex/index buffers, procedural shape generation, and InstancedMesh optimization.
- **`threejs-materials`**: Physically-Based Rendering (PBR) workflows with `MeshStandardMaterial` and `MeshPhysicalMaterial`, subsurface scattering, transmission, and custom shader extensions.
- **`threejs-lighting`**: Directional, spot, point, ambient lighting setups, soft shadow maps, environment lighting, and HDRI image-based lighting (IBL).
- **`threejs-textures`**: UV mapping, texture mipmapping, anisotropy, cubemaps, normal maps, roughness/metalness maps, and canvas textures.
- **`threejs-loaders`**: Asynchronous model loading with `GLTFLoader`, Draco compression decoding, texture loading managers, and preloading states.
- **`threejs-animation`**: Keyframe tracks, `AnimationMixer`, skeletal rigging playback, morph target transitions, and procedural motion.
- **`threejs-interaction`**: Raycasting for 3D mouse/pointer picking, bounding box hit testing, OrbitControls, and custom drag/orbit gestures.
- **`threejs-postprocessing`**: `EffectComposer` pipelines, selective Bloom, Depth of Field (Bokeh), chromatic aberration, film grain, and vignette shaders.
- **`threejs-shaders`**: Custom `ShaderMaterial` and `RawShaderMaterial`, vertex displacement, fragment shaders, time uniforms, and noise generation.

### 2. High-End 3D Web & Interactive Experiences
- **`3d-web-experience`**: Expert workflows combining Three.js, React Three Fiber (R3F), Spline, and WebGL for interactive 3D product configurators, hero sections, and immersive portfolios.
- **`premium-3d-website`**: Awwwards/FWA-grade architectural guidelines for custom WebGL shaders, physics-based interactions, smooth preloader sequences, and GPU tier-based performance scaling.
- **`spline-3d-integration`**: Embedding interactive 3D scenes from Spline.design into modern web projects with real-time variable control and trigger events.
- **`shader-programming-glsl`**: Complete GLSL shader programming reference covering vertex/fragment pipeline, swizzling, uniforms, varyings, raymarching, and procedural textures.
- **`web-games`**: Browser runtime architecture across Canvas, WebGL, WebGPU, Three.js, and Babylon.js with framerate stabilization.

---

### 3. Spatial & 3D UI / Aesthetics
- **`3d-ui`**: Design and implementation of real 3D objects, spatial depth, perspective projection, and depth-layered interfaces.
- **`spatial-design`**: Environment-aware layouts, Apple Vision Pro spatial computing paradigms, and z-space hierarchy.
- **`spatial-computing-ui`**: Floating UI glass panels, depth responsiveness, and multi-planar interactive affordances.
- **`holographic-ui`**: Translucent glowing materials, HUD projections, grid animations, and futuristic light-based aesthetics.
- **`isometric-design`**: Orthographic projection, isometric grids, and technical 3D isometric illustrations.
- **`claymorphism`**: Tactile, soft 3D UI components, inflated buttons, and diffuse multidirectional shadows.
- **`glassmorphism`**: Frosted glass blur (`backdrop-filter`), refraction, specular edge highlights, and layered depth.

### 4. 3D Web Mechanics, Motion & Performance
- **`antigravity-design-expert`**: UI/UX engineering for spatial, weightless, and glassmorphic interfaces with GSAP and 3D CSS transforms.
- **`scroll-experience`**: Scroll-driven storytelling, parallax depth, 3D model camera pinning, and seamless synchronization with Lenis and GSAP ScrollTrigger.
- **`gpt-taste`**: Elite GSAP-heavy creative frontend architecture, dynamic pacing, and interactive micro-interactions.
- **`animejs-animation`**: Complex JavaScript animation sequencing, SVG path morphing, and canvas animation timelines.
- **`ui-motion`**: Personality-driven spring physics and motion presets (Spring, Silk, Snap, Float, Pulse).
- **`fixing-motion-performance`**: Diagnostic checklists for 60/120 FPS lock, layout thrashing prevention, GPU memory leak mitigation, and render cycle optimization.
- **`review-animations`**: Strict craft, performance, and accessibility (prefers-reduced-motion) audit checklist.

## 💡 How Antigravity Uses These Skills

Antigravity uses **progressive disclosure**:
1. Skill names and triggers are registered automatically.
2. Whenever you ask to build a 3D website, configure a Three.js scene, write a GLSL shader, embed Spline models, or add spatial glassmorphic UI, Antigravity dynamically loads the relevant skill's instructions and best practices into context.
